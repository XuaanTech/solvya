A **QR code (Quick Response)** stores information in a dot matrix that any phone reads instantly. Our **free QR generator** creates unlimited static codes, **no registration**, **no watermark** and **all in your browser** (total privacy).

## Supported QR types

| Type | Typical use | Fields |
|------|-------------|--------|
| **URL** | Web, landing, social | `https://...` |
| **Text** | Notes, codes, keys | Free text (up to ~2.9 KB) |
| **WiFi** | Guests, offices | SSID, password, WPA/WEP/open, hidden |
| **vCard** | Business cards | Name, phone, email, org, title, web, address |
| **Email** | Quick contact | `mailto:email?subject=...&body=...` |
| **SMS** | Campaigns, support | Number + predefined message |
| **Phone** | Click-to-call | `tel:+15551234567` |
| **Geo** | Maps, events | Latitude, longitude |
| **Event (iCal)** | Calendar | Title, start/end, location, description |

> **Real limit**: a v40 QR (max) holds ~2.9 KB (≈ 4,200 alphanumeric chars). For long URLs, use a shortener first.

## Advanced customization

| Option | Recommendation |
|--------|----------------|
| **Foreground color** | Dark on light background (contrast ≥ 4.5:1 for accessibility). |
| **Background color** | White or very light. Avoid gradients or background images. |
| **Center logo** | PNG/SVG with transparency. Size ≤ 20–25 % of QR. Error correction **M (15 %)** or **Q (25 %)**. |
| **Margin (quiet zone)** | Minimum 4 modules (standard). Increase if framing or colored background. |
| **Error correction** | **L (7 %)** = more data, less robustness. **M (15 %)** = balance. **Q (25 %)** = with logo. **H (30 %)** = dirty/industrial environments. |

## PNG vs SVG: which to download?

| Format | Advantages | Use for |
|--------|------------|---------|
| **PNG** | Ready for web, email, Office, standard offset print | Web, social media, A5/A4 flyers, business cards |
| **SVG** | Vector, infinite scaling, editable in Illustrator/Figma/Sketch | Large signage, vinyl, packaging, brand master |

> **Tip**: download **both**. Use PNG for web and SVG for any professional print.

## Best practices (checklist before printing)

- [ ] **Contrast**: dark color on light (black on white is safest).
- [ ] **Quiet zone**: minimum 4 modules margin (don't place text/images at the edge).
- [ ] **Minimum size**: 2 × 2 cm (≈ 76 × 76 px at 96 DPI) for reliable scanning.
- [ ] **Real test**: scan **with 2 different phones** (iOS + Android) before sending to print.
- [ ] **Short URL**: if URL exceeds ~100 chars, shorten it (bit.ly, your domain) → cleaner, faster QR.
- [ ] **Logo**: if using logo, bump error correction to **Q** or **H**.
