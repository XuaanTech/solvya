El **porcentaje de grasa corporal** mide lo que el IMC no: **cuánto de tu peso es tejido adiposo**. Una persona de 80 kg y 1.80 m tiene IMC 24.7 ("normal"), pero si su grasa es el 30 % tiene obesidad metabólica; si es el 12 % es atlética. Aquí comparas métodos, rangos y cuándo usar cada uno.

## Por qué el IMC se queda corto

| Perfil | IMC | % Grasa real | Interpretación |
|--------|-----|--------------|----------------|
| Culturista | 28 | 10 % | "Sobrepeso" falso |
| Sedentario "normal" | 23 | 28 % | "Normal" falso (obesidad sarcopénica) |
| Anciano frágil | 22 | 35 % | Riesgo alto invisible |

El IMC **no distingue masa magra de grasa**. El % graso sí.

## Métodos de medición: precisión vs accesibilidad

| Método | Precisión (error) | Coste | Acceso | Uso ideal |
|--------|-------------------|-------|--------|-----------|
| **DEXA** (rayos X) | ±1–2 % | Alto | Clínica/gimnasio premium | Oro clínico, composición regional |
| **Bod Pod** (desplazamiento aire) | ±2–3 % | Medio | Universidades/dep. elite | Investigación, atletas |
| **Plicómetro** (pliegues cutáneos) | ±3–4 % (técnico bueno) | Bajo | Cualquier gym/casa | Seguimiento barato, fiable si técnica buena |
| **Bioimpedancia (BIA)** profesional (InBody, Tanita pro) | ±3–4 % | Medio | Gym/nutricionista | Seguimiento periódico |
| **BIA báscula casa** | ±4–6 % | Bajo | Casa | **Solo tendencias** (mismas condiciones) |
| **Circunferencia cintura** | Proxy indirecto | Cero | Casa | Cribado riesgo metabólico rápido |

> **Regla práctica**: para seguir tu evolución en casa, **BIA cada 2–4 semanas en mismas condiciones** (mañana, ayunas, hidratación similar). Para una foto real, **DEXA 1–2 veces al año**.

## Rangos de referencia (adultos)

| Categoría | Hombres | Mujeres |
|-----------|---------|---------|
| Grasa esencial | 2–5 % | 10–13 % |
| Atletas | 6–13 % | 14–20 % |
| Fitness | 14–17 % | 21–24 % |
| Promedio saludable | 18–24 % | 25–31 % |
| Sobrepeso / riesgo | 25–29 % | 32–39 % |
| Obesidad | ≥ 30 % | ≥ 40 % |

*(Valores basados en ACSM / ACE / OMS. Varían ligeramente por edad.)*

## La tríada ganadora: IMC + % graso + cintura

| Cintura (cm) | Hombres | Mujeres | Riesgo metabólico |
|--------------|---------|---------|-------------------|
| Bajo | < 94 | < 80 | Bajo |
| Aumentado | 94–102 | 80–88 | Moderado |
| Alto | > 102 | > 88 | Alto |

**Combinación diagnóstica**:
- IMC alto + cintura normal + % graso normal → **falso positivo IMC** (musculado).
- IMC normal + cintura alta + % graso alto → **obesidad de peso normal** (riesgo real).

## Conclusión

El **IMC es un cribado poblacional barato**; el **% graso es tu indicador individual**. Usa BIA casera para tendencias, plicómetro si aprendes la técnica, y DEXA de referencia anual. Y **mide tu cintura**: es el predictor cardiovascular más barato y potente.
